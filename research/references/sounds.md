# Sounds (reference)

Source all audio from Freesound (CC0/CC-BY) and log it in ASSETS.md. Record locally only with consent.

| Zone | Layers |
|---|---|
| Hub | hawkers calling, gengetone/bongo from shop speakers (royalty-free substitutes), matatu horns, boda engines, roosters, dogs, kids playing, jiko crackle, radio talk in Swahili |
| Matatu stage | touts shouting destinations ("Tao! Tao! Panda tuende!"), engines idling, hooting, coins |
| School | bell (metal rim struck with a rod), kids chatter, whistle |
| Backlot | generator hum, crew chatter, "Action!", clapperboard |
| CBD | traffic hum, crowd murmur, traffic police whistle, preacher with a megaphone |
| Savanna | crickets, wind in grass, fire crackle, distant city hum |
| Arena | crowd roar, PA |
| Weather | rain on mabati (very loud, distinctive), thunder |
